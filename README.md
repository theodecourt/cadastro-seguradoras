# Cadastro e Nomeacao Seguradoras - Segura

Formulario estatico de cadastro e nomeacao de corretoras.

- Pagina publicada: https://theodecourt.github.io/cadastro-seguradoras/
- O envio vai para um Catch Hook do Zapier e cai no canal #cadastro-seguradoras do Slack.
- Para trocar o destino, edite CONFIG.WEBHOOK_URL no topo do <script> em index.html.
